# Code of Conduct

Contributors, maintainers, and community members are expected to keep project spaces welcoming and constructive.

Examples of behavior that supports this standard include:

- Using respectful language and considering different viewpoints.
- Giving specific, actionable feedback about code and behavior.
- Accepting corrections and discussing disagreements without personal attacks.
- Respecting privacy and avoiding the publication of private information.

Harassment, threats, discriminatory language, repeated unwanted contact, and deliberate disruption are not acceptable. Project maintainers may edit or remove content and restrict participation when necessary to protect contributors.

Report conduct concerns privately to a project maintainer. Do not include private information in a public issue.
